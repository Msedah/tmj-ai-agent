# TMJ AI Agent

TMJ AI Agent is an education-only AI assistant designed specifically for North-West University (NWU) students.

## Core principles
- NWU university modules are the primary focus.
- Official NWU resources are prioritised whenever relevant.
- Student-provided module material takes priority for module-specific explanations.
- The agent refuses non-academic requests.
- Conversations can be saved to a user account.
- Developer: TJ Mailula
- Developer email: mailulajosep@gmail.com

## Source priority
1. Official NWU resources and module material available to the application.
2. Student-uploaded module documents.
3. Reputable academic sources.
4. General web sources only when necessary.

## MVP stack
- Frontend: plain HTML/CSS/JavaScript
- Authentication/database: Supabase
- AI endpoint: Netlify Function
- Deployment target: Netlify

See `docs/ARCHITECTURE.md` and `supabase/schema.sql` before configuring production services.
